# QUIZ GAME

## this quiz game is about nelson Mandela history. five questions and five options
it talks about years and ages of the incident of during the time of nelson Mandela.

there are 5 questions and from 5 options each option matches with the question but the user have to
chose the one which is correct

the expected points if all answers are correct are 25 points

if the user gets more than 20 points, then that is fantastic
if the user gets between 16 and 19 points then the user did very good
if the user gets exactly 15 points then the user did good.
if the points are less than 10, then that is bad. the user should try again.
if all answers are zero then the result is false.
